# OverTheWire Bandit

> Learning Linux, problem-solving, and cybersecurity one level at a time.

This repository documents my journey through **[OverTheWire Bandit](https://overthewire.org/wargames/bandit/)**, a beginner-friendly wargame designed to teach the fundamentals needed to approach other cybersecurity challenges.

I'm using Bandit as part of my cybersecurity learning journey, particularly to become more comfortable with the Linux command line and develop a more practical problem-solving mindset.

## Why Bandit?

Learning cybersecurity isn't just about memorizing commands or tools.

It's about learning how to:

- Explore unfamiliar environments
- Break a problem into smaller pieces
- Investigate when something doesn't make sense
- Read documentation and man pages
- Experiment with different approaches
- Understand why a solution works instead of simply memorizing it

Bandit provides a hands-on way to practice these skills through progressively challenging levels.

## What This Repository Contains

Each level has its own writeup containing:

- **Level Objective** — What the challenge asks
- **Approach** — How I approached the problem
- **Commands Used** — Commands involved in the solution
- **Explanation** — What the commands and concepts actually do
- **What I Learned** — Key takeaways from the challenge

> Passwords and other credentials are intentionally excluded from these writeups.

## Disclaimer

This repository is intended as a **learning journal and reference**, not as a shortcut to completing Bandit.

If you're working through the wargame yourself, I recommend trying each challenge independently before looking at a solution.

The goal isn't just to reach the next level.

It's to understand **how you got there**.
